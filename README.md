# React + Vite

Учебный проект React, созданный с использованием Vite.

## Подготовка к работе

1. Установи LTS-версию Node.js: https://nodejs.org/
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Запусти проект в режиме разработки:

   ```bash
   npm run dev
   ```

4. Открой адрес, указанный в терминале (обычно http://localhost:5173/).

## Доступные команды

- `npm run dev` — запуск сервера разработки.
- `npm run build` — создание production-сборки.
- `npm run lint` — проверка кода ESLint.
- `npm run preview` — просмотр production-сборки.

## Структура проекта

- `src/` — исходный код приложения.
- `public/` — статические файлы.
- `index.html` — HTML-файл приложения.
- `vite.config.js` — конфигурация Vite.
- `package.json` — зависимости и команды проекта.
